🚗 Vehicle Showroom Management System

A simple Java mini project that allows users to view different car brands, car models, and their price ranges using a console-based application.

📌 Features
- View multiple car brands
- Display car models with base and premium prices
- Filter cars based on budget
- Console-based user interaction
- Beginner-friendly Java project

🛠️ Technologies Used
- Java
- OOP Concepts
- HashMap
- Scanner Class

📂 Project Structure
- `VehicleCompany` class → Handles company details and car data
- `Main` class → Runs the application and manages user interaction

▶️ How to Run

Compile the program:
```bash
javac Main.java
```

Run the program:
```bash
java Main
```

